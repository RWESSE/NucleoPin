How to use NucleoPin

  1. Create or select a project in NucleoPin.
  2. Add your STM32CubeMX .ioc file to the project. NucleoPin remembers its original location.
  3. Use Real Board for a physical view of the NUCLEO board, or switch to Classic Pinout for the connector layout.
  4. Use Physical or Project view and the All, Used, Free, GPIO, Comms and ADC filters to focus the board.
  5. Click or hover a pin to see its MCU pin, Arduino alias, CubeMX label, signal and physical connector locations.
  6. Use Find Free Pin to highlight suitable unused GPIO, ADC, PWM, UART, I²C or SPI pins on both Real Board and Classic Pinout.
  7. Use Components and the Wiring List to plan and document your breadboard connections.
  8. Run Smart Project Check before wiring to review conflicts and NUCLEO board-specific warnings.
  9. Use Open in CubeMX when you need to change the MCU configuration. Save in CubeMX and NucleoPin will reload the IOC.
  10. Use Print Pinout for the A4 project printout. Printing always uses the Classic Pinout layout.
NucleoPin treats your .ioc as read-only. It reads the original file from your computer and never modifies it.
